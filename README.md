# Nibraas Navas - Personal Portfolio Website

Personal portfolio website of **Nibraas Navas**, Data Science & Machine Learning Engineer.

## 🚀 Built With
- **HTML5** & **Vanilla CSS3** (Custom Modern Glassmorphism & Micro-animations)

- **Skills Matrix & Certifications**
- **Responsive Navigation & Clean UI/UX**
